Die Anwendung wird von der vorgenannten Gesellschaft betrieben. Sie sichert Projektdaten des Salus Global Club, die in einem Google-Drive-Konto der Gesellschaft gespeichert sind.

2 Zweck der Anwendung

„rclone SGC Backup“ erstellt automatisierte Sicherungskopien eines Projektordners in Google Drive. Ziel ist der Schutz vor versehentlichem Löschen und vor Datenverlust beim Ausscheiden von Mitarbeitenden.

3 Zugriff auf Google-Nutzerdaten

Die Anwendung nutzt die Google Drive API mit dem Berechtigungsbereich https://www.googleapis.com/auth/drive. Dieser Bereich ist erforderlich, weil die Anwendung Dateien lesen muss, die anderen Personen gehören, und Kopien davon anlegen muss. Google bietet keinen auf einen einzelnen Ordner begrenzten Berechtigungsbereich an.

Verarbeitet werden dabei:

  • Metadaten von Dateien und Ordnern (Name, Größe, Änderungszeitpunkt, Ablageort)
  • Dateiinhalte, ausschließlich zum Zweck des Kopierens innerhalb desselben Google-Kontos

4 Wo die Daten bleiben

  • Der Kopiervorgang wird serverseitig von Google ausgeführt. Dateiinhalte verlassen Google Drive nicht und werden nicht auf den ausführenden Rechner heruntergeladen.
  • Quelle und Ziel liegen im selben Google-Konto.
  • Es findet keine Übertragung an Server des Betreibers oder an Dritte statt.
  • Es werden keine Daten für Werbung, Profilbildung, Modelltraining oder Weiterverkauf verwendet.

5 Lokal gespeicherte Zugangsdaten

Auf dem ausführenden Rechner wird ein OAuth-Zugriffstoken gespeichert, das den Zugriff auf Google Drive erlaubt. Es enthält kein Passwort. Die betroffene Person kann diese Berechtigung jederzeit unter myaccount.google.com/permissions widerrufen; die Anwendung verliert damit sofort jeden Zugriff.

Zusätzlich wird ein Protokoll jedes Sicherungslaufs lokal abgelegt. Es enthält Dateinamen und Pfade, keine Dateiinhalte, und wird nach 90 Tagen automatisch gelöscht.

6 Google API Services User Data Policy

Die Nutzung der von Google APIs empfangenen Informationen durch diese Anwendung erfolgt im Einklang mit der Google API Services User Data Policy, einschließlich der darin enthaltenen Limited-Use-Anforderungen.
